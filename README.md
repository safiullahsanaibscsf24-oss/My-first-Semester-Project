# C++ Programming Project

## Description
This repository contains my basic C++ programs practiced during learning. The programs cover fundamental concepts of C++ programming.

## Topics Covered
- Variables and Data Types  
- Input and Output  
- Conditional Statements (if-else)  
- Loops (for, while, do-while)  
- Functions  
- Arrays (basic level)

## Files Included
- main.cpp  
- other practice programs (.cpp files)

## How to Run
1. Open the project in any C++ compiler (CodeBlocks, Dev C++, or VS Code).
2. Compile the `.cpp` file.
3. Run the program.

## Purpose
This project is created for learning and practicing C++ programming concepts.
